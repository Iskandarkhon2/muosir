# Муосир пласт (Muosir Plast) — Экспортный B2B Landing Page & Admin Console

Комплексный B2B-сайт и панель управления для завода-производителя жесткой пластиковой упаковки **«Муосир пласт»**. Производство находится в Б. Гафуровском районе Согдийской области.

Публичный контент опирается на подтвержденные сведения о производственных мощностях, технологиях, адресах и контактах. Неподтвержденные сертификаты, сроки поставки и таможенные условия не заявляются.

---

## 🚀 Быстрый запуск

Локальный сервер хранит заявки в `data/leads.json`, вложения — в `data/lead-attachments/`. На Vercel API работает как serverless-функция: заявки и сессии хранятся в Neon PostgreSQL, а вложения — в закрытом Vercel Blob. Локальные файлы не переносятся в облако автоматически.

### Первичная настройка администратора

Требуется Node.js 20 или новее. В PowerShell из корневой папки проекта задайте логин и безопасный scrypt-хэш пароля. Пароль вводится без отображения символов; хэш не сохраняется в репозитории:
```powershell
$env:ADMIN_USERNAME = "admin"
$env:ADMIN_PASSWORD_HASH = node .\scripts\create-admin-hash.js
```

Команда генерации требует интерактивный терминал и пароль длиной не менее 14 символов. Затем, не закрывая это окно PowerShell, запустите локальный сервер:
```powershell
npm start
```

Сайт доступен по адресу:
- Главная: [http://localhost:3000/](http://localhost:3000/)
- Вход в панель: [http://localhost:3000/admin-login.html](http://localhost:3000/admin-login.html)

Панель администратора показывает данные только после успешной проверки сессии; API заявок, скачивание вложений и CSV-экспорт защищены серверной сессией. Локальная сессия хранится в памяти процесса, поэтому после перезапуска нужно войти снова. На Vercel сессии хранятся в Neon. Локальное хранилище и backend Vercel независимы.

Для остановки нажмите `Ctrl+C` в терминале.

Все HTML-страницы используют ES-модули для настройки темы и работают через HTTP-сервер. Прямое открытие через `file://` не поддерживается браузерами для модульных скриптов.

### Развёртывание на Vercel

Статические страницы публикуются как файлы, API — как Node.js Vercel Function из `api/index.mjs`. Перед первым запросом API автоматически создаёт таблицы в Neon.

1. Создайте проект Neon и добавьте его connection string в Vercel как `DATABASE_URL`.
2. В разделе **Storage** проекта Vercel создайте Blob store с доступом **Private**, подключите его к проекту и включите добавление `BLOB_READ_WRITE_TOKEN`. Этот секрет нужен для защищённой выдачи разрешения на прямую загрузку файлов из браузера.
3. В **Settings → Environment Variables** добавьте `ADMIN_USERNAME` и `ADMIN_PASSWORD_HASH`. Сгенерируйте новый хэш: прежний пароль/хэш, опубликованный в чате, использовать нельзя.
4. Настройте переменные для **Production** и, если нужны предварительные деплои, для **Preview**. Запустите Redeploy.

На Vercel заявки, вложения и сессии доступны из разных экземпляров функций и не пропадают при redeploy. Существующие локальные заявки из `data/leads.json` не импортируются автоматически — перед переключением production их нужно отдельно перенести. Доступ к вложениям защищён входом администратора; форма загружает файлы напрямую в закрытый Blob, не передавая файлы размером до 15 МБ через API-функцию.

## Архитектура

Публичные HTML-страницы остаются в корне, чтобы сохранить статические URL и поисковую индексацию. Код сгруппирован по функциям в `src/`:

- `src/app/` — запуск главной страницы и ранняя/интерактивная настройка темы.
- `src/features/site/` — общие элементы интерфейса.
- `src/features/catalog/` — единая загрузка и нормализация данных каталога, фильтрация и отображение товаров.
- `src/features/admin/` — панель управления.
- `src/features/forms/` — общая отправка заявок, валидация вложений и серверный API-клиент.
- `src/features/localization/` — языковые словари и переключение.
- `src/features/analytics/` — аналитика и UTM-метки.
- `src/serverless/` — serverless API для Vercel, Neon и Vercel Blob.
- `src/features/motion/` — scroll-reveal, переходы и доступные микроанимации.
- `src/features/visualizer/` — 2D-визуализация логотипа на упаковке.
- `src/shared/data/`, `src/shared/styles/` — общие данные и CSS-дизайн-система.
- `src/shared/styles/tokens.css` — единые светлые/тёмные цветовые и motion-токены.

Tailwind используется только на этапе сборки CSS (`npm run build:css`); браузерного Tailwind runtime нет. Публичные формы отправляют данные через `POST /api/leads`; honeypot и ограничение запросов действуют на сервере. На Vercel документы PDF, Excel и Word размером до 15 МБ напрямую загружаются в закрытый Blob store. Заявки доступны только через защищённые API администратора.

Настройка темы выполняется на всех страницах из `src/app/theme-init.js` до загрузки стилей; переключатель и синхронизация настроек между вкладками реализованы в `src/app/theme.js`.

### Блокеры перед публичным запуском

1. Настроить `DATABASE_URL`, `BLOB_READ_WRITE_TOKEN`, `ADMIN_USERNAME` и новый `ADMIN_PASSWORD_HASH` в Vercel; проверить резервное копирование Neon и закрытого Blob перед публикацией.
2. Проверить каждый PDF в `assets/docs` у владельца документов и публиковать сертификаты только после подтверждения подлинности, срока и области действия.
3. Получить и разместить утверждённые фото/видео производства, сведения о наградах и профиль экспорт-менеджера либо явно исключить эти пункты из объёма запуска.
4. Согласовать операционный процесс вложений: файлы сохраняются вместе с заявкой на сервере, а для мгновенного ответа WhatsApp пользователь может приложить их повторно в диалоге.
5. Собирать статический Tailwind CSS командой `npm run build:css` перед публикацией; браузерный runtime удалён.
6. Перед релизом дополнить sitemap страницами, определить стратегию canonical/языковых URL и проверить рабочий домен/HTTPS.

## 🔑 Панель администратора (`admin.html`)

- **Вход:** `admin-login.html` отправляет логин и пароль на `POST /api/admin/login`. Пароль проверяется по scrypt-хэшу из переменной `ADMIN_PASSWORD_HASH`; клиентского пароля и доверия к `sessionStorage` нет.
- **Сессия:** сервер выдает HttpOnly/SameSite=Strict cookie с восьмичасовым сроком действия. Страница `admin.html`, список лидов, CSV-экспорт, скачивание вложений и удаление требуют активной сессии.
- **Заявки:** публичные формы используют `POST /api/leads`; honeypot-запросы не сохраняются, лимит — пять заявок с IP за минуту. Данные и вложения хранятся вне публичной директории в `data/`.
- **Разделы панели:**
  1. **Каталог продукции:** Добавление, редактирование (наименование, материал PP/PET/PS, объем, диаметр, партия, фото) и удаление товаров.
  2. **Входящие заявки (Лиды):** Серверный список запросов с датой, страной, компанией, выбранным товаром и UTM-метками. Кнопка WhatsApp, защищённый CSV-экспорт и удаление.
  3. **Тексты и статистика:** Редактирование текстов и опубликованных производственных показателей.
  4. **Контакты и WhatsApp:** Изменение номера телефона, WhatsApp (+992 92 299 2000), email и адреса.
  5. **Документы:** Управление записями документов; перед публикацией необходимо проверить файлы и подтверждающие сведения.
  6. **Реклама и интеграции:** Ввод Meta Pixel ID, GA4 ID, Telegram Webhook URL и CRM Webhook URL (Битрикс24 / amoCRM).
  7. **Бэкап:** JSON-импорт/экспорт локальных настроек сайта; серверные заявки необходимо отдельно резервировать из `data/`.

## 🌐 Мультиязычность

В интерфейсе предусмотрено переключение словарей на 4 языка:
- **RU** — Русский (базовый язык экспорта)
- **EN** — English (международные B2B партнеры)
- **UZ** — O'zbekcha (ключевой экспортный рынок Узбекистана)
- **KK** — Қазақша (рынок Республики Казахстан)

Словари находятся в [src/features/localization/i18n.js](./src/features/localization/i18n.js). Перевод покрывает не весь статический текст страниц; языковые варианты используют общие URL и не являются отдельными индексируемыми версиями.
