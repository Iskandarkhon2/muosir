# Муосир пласт (Muosir Plast) — Экспортный B2B Landing Page & Admin Console

Комплексный экспортный B2B Landing Page и панель управления для завода-производителя жесткой пластиковой упаковки **«Муосир пласт»** (г. Худжанд, Республика Таджикистан).

Проект полностью реализован и выверен в точном соответствии с **10-страничным Техническим заданием (ТЗ)** заказчика, охватывая все **27 тематических разделов**.

---

## 🚀 Быстрый запуск

Сайт полностью автономен, не требует сторонних серверов баз данных или сложных систем сборки:

### Способ 1. Запуск через локальный веб-сервер
В папке проекта запустите `start-server.ps1` (правой кнопкой -> *Выполнить с помощью PowerShell*) или выполните в консоли:
```powershell
powershell -ExecutionPolicy Bypass -File .\start-server.ps1
```
Сервер будет доступен по адресам:
- Главный Landing Page: [http://localhost:3000/](http://localhost:3000/)
- Панель администратора: [http://localhost:3000/admin.html](http://localhost:3000/admin.html)

### Способ 2. Прямое открытие в браузере
Дважды кликните на `index.html` или `admin.html` — сайт работает без сборки и базы данных. Визуализатор логотипа использует локальную 2D-композицию в браузере.

## Архитектура

Публичные HTML-страницы остаются в корне, чтобы сохранить статические URL и поисковую индексацию. Код сгруппирован по функциям в `src/`:

- `src/features/site/` — общие элементы интерфейса и главная страница.
- `src/features/catalog/` — фильтрация и отображение каталога.
- `src/features/admin/` — панель управления.
- `src/features/localization/` — языковые словари и переключение.
- `src/features/analytics/` — аналитика и UTM-метки.
- `src/features/motion/` — scroll-reveal, переходы и доступные микроанимации.
- `src/features/visualizer/` — 2D-визуализация логотипа на упаковке.
- `src/shared/data/`, `src/shared/styles/`, `src/shared/vendor/` — общие данные, стили и локальная зависимость.

## 🔑 Панель администратора (`admin.html`)

- **Пароль по умолчанию:** `muosir2026`
- **Разделы панели:**
  1. **Каталог продукции:** Добавление, редактирование (наименование, материал PP/PET/PS, объем, диаметр, партия, фото) и удаление товаров.
  2. **Входящие заявки (Лиды):** Просмотр всех запросов с датой, страной, компанией, выбранным товаром и UTM-метками. Кнопка моментального перехода в WhatsApp к клиенту. Экспорт в CSV/Excel.
  3. **Тексты и статистика:** Редактирование заголовков оффера и 6 подтвержденных заводских метрик.
  4. **Контакты и WhatsApp:** Изменение номера телефона, WhatsApp (+992 92 299 2000), email и адреса.
  5. **Сертификаты и ГОСТ:** Управление документами качества и ссылками на PDF.
  6. **Реклама и интеграции:** Ввод Meta Pixel ID, GA4 ID, Telegram Webhook URL и CRM Webhook URL (Битрикс24 / amoCRM).
  7. **Бэкап:** Полная выгрузка базы в JSON и восстановление в 1 клик.

## 🌐 Мультиязычность

Поддерживаются 4 языка целевых рынков:
- **RU** — Русский (базовый язык экспорта)
- **EN** — English (международные B2B партнеры)
- **UZ** — O'zbekcha (ключевой экспортный рынок Узбекистана)
- **KK** — Қазақша (рынок Республики Казахстан)

Словарь находится в [src/features/localization/i18n.js](./src/features/localization/i18n.js). Добавление новых языков осуществляется добавлением ключей без изменения верстки.
